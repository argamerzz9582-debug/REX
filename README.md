# REX One-Click Reverse Engineering Toolchain

One-command installation and verification repository for AI agents and developers.

## One-Line Clone & Run

```bash
git clone https://github.com/<your-username>/REX-one-click.git && cd REX-one-click && chmod +x install.sh && ./install.sh
```

## Included Files
- `AGENT.md` — One-command AI agent entrypoint instructions
- `REX-main/AGENT.md` — Full Reverse Engineering Toolkit Setup Agent specification
- `REX-main/TOOLS.md` — Complete 12-category Reverse Engineering Tool Manifest
- `manifest.json` — Structured JSON manifest covering all 158 entries
- `install.sh` — Idempotent installer, verifier, and `ledger.json` generator
